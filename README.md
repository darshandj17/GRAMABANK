# GRAMABANK AI
GramBank AI is a voice-first, multilingual financial literacy assistant designed for rural and underserved communities in India.

## Features

- 🤖 AI-powered banking assistant
- 🎙️ Voice input and voice responses
- 🌐 Multilingual support
- 📚 Banking policy simplification
- 🛡️ Fraud and scam awareness
- 🏦 Government scheme information
- 🧠 Financial literacy quizzes
- ✅ Verified-source indicators
- ⚙️ Admin content management

## Technology

- HTML5
- CSS3
- JavaScript
- Gemini API
- Web Speech API
- LocalStorage

## Run Locally

Open `index.html` in a modern browser.

For voice features, Chrome/Edge is recommended.

## Gemini API

Add your Gemini API key from the Profile/Admin section and use **Save & Test Gemini**.

> For production deployment, the Gemini API key should be moved to a secure backend instead of exposing it in client-side JavaScript.

## Project Purpose

Built as a hackathon prototype to improve financial literacy, banking awareness, and fraud prevention for underserved users.
